# PG 관리자 웹 시스템

결제 게이트웨이(PG) 관리를 위한 웹 기반 관리자 시스템입니다.

## 주요 기능

### 1. 결제내역 관리 (index.html)
- 결제 내역 목록 조회
- 고객처리 및 추천인처리 상태 확인
- 결제금, 환불금, 추천인수수료 관리
- 검색 및 페이지네이션 기능

### 2. 정산현황 (settlement.html)
- 기간별 정산 현황 조회
- 결제금 합계, PG수수료 합계
- 고객환불금 합계, 추천인 합계
- 정산입금 완료 및 미정산 금액 확인

### 3. 추천인관리 (referral.html)
- 추천인 목록 조회 및 관리
- PG수수료, 영업수수료, 고객환도율 설정
- 추천인 상태 관리 (사용/중지)
- 추천인 정보 검색

### 4. 결제내역 수정 (edit.html)
- 추천인 정보 상세 조회 및 수정
- 고객 정보 상세 조회 및 수정
- 처리 상태 변경
- 관리자 메모 관리

## 기술 스택

- **HTML5**: 웹 페이지 구조
- **CSS3**: 반응형 디자인 및 스타일링
- **JavaScript**: 인터랙티브 기능 구현

## 파일 구조

```
/
├── index.html          # 결제내역 페이지
├── settlement.html     # 정산현황 페이지
├── referral.html       # 추천인관리 페이지
├── edit.html          # 결제내역 수정 페이지
├── css/
│   └── style.css      # 전체 스타일시트
├── js/
│   └── main.js        # JavaScript 기능
└── README.md          # 프로젝트 설명
```

## 디자인 특징

- **색상 구분**:
  - 파란색 (#007bff): 추천인 정보 섹션
  - 녹색 (#28a745): 고객 정보 섹션
  - 주황색 (#ff6600): 관리자 메모 섹션

- **반응형 디자인**:
  - 데스크톱, 태블릿, 모바일 지원
  - 미디어 쿼리를 통한 적응형 레이아웃

- **사용자 경험**:
  - 직관적인 탭 네비게이션
  - 클릭 가능한 테이블 행
  - 상태별 색상 구분
  - 접기/펼치기 가능한 섹션

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다.
2. 상단의 탭을 클릭하여 다른 페이지로 이동합니다.
3. 검색 기능을 사용하여 원하는 데이터를 찾습니다.
4. 테이블의 행을 클릭하여 상세 정보를 확인하고 수정합니다.
